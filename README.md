# Lyceum Life

Лицейдің олимпиадаға дайындықтары, үйірмелері, курстары, іс-шаралары, жарыстары мен турнирлері бір жерде.
Оқушы іс-шара ұсынады → сынып жетекшісі → тәрбие ісі жөніндегі орынбасар растайды → барлығына көрінеді.

## Стек
- Фронтенд: Vite + React + TypeScript + Tailwind v4 (`src/tokens.css` — дизайн токендері)
- Бэкенд: Supabase (Postgres + RLS + RPC функциялар + Auth + Edge Functions)
- Кіру: ЖСН + құпия сөз (Supabase Auth, email = `<ЖСН>@users.lyceum-life.app`, хат жіберілмейді). Telegram кіру — кейін.

## Іске қосу
```bash
cp .env.example .env.local   # VITE_SUPABASE_URL, VITE_SUPABASE_KEY толтыру
npm install
npm run dev
```

## Құрылым
- `supabase/migrations/*.sql` — дерекқор схемасы, RLS, бизнес-логика (RPC)
- `supabase/functions/admin-users` — пайдаланушы қосу (тек қызметкерлер) және бастапқы демо-деректер
- `src/lib/api.ts` — дерекқормен жұмыс істейтін барлық функция осында
- `src/screens/*` — экрандар

## Рөлдер
| рөл | не істей алады |
|---|---|
| student | іс-шара ұсыну, жазылу, рұқсат сұрау |
| teacher | іс-шара құру (орынбасар растайды), өз іс-шарасының журналын жүргізу |
| class_teacher | teacher + өз сыныбы оқушыларының ұсыныстарын растау, оқушы қосу |
| deputy | барлық ұсынысты түпкілікті растау, кез келген пайдаланушыны қосу |

## Ережелер
Барлық күй өзгерістері (ұсыну, растау, жазылу, журнал) тек дерекқордағы `security definer` функциялар арқылы өтеді;
кестелерге клиенттен тікелей жазуға RLS рұқсат бермейді.
